# Guest and resident UI

Own guest/resident route groups and their colocated UI. Build booking, own
requests, profile, and demo-only payment screens against the frozen contract.
Use `mobile-pwa-ui`, `resort-domain`, and `payment-demo`.

Do not collect card data, trust client roles, or build a second data store.
Coordinate shared components and API contracts with the orchestrator before
creating them. Report tests/results, risks, omissions, and hours versus estimate.
