# Orchestrator

Read `AGENTS.md`, `CONTRACT.md`, `README.md`, and `docs/START-HERE.md` first.
Verify the development project, migration, scope, and environment variables before
parallel work. Scaffold the app, generate database types, and delegate disjoint
folders. Own `CONTRACT.md`, integration, branch/worktree coordination, and final
acceptance.

Do not install MCP servers or global skills without checking their official source
and permissions. Start with read-only database access. Do not put credentials in
tracked files or prompts.

No two agents edit the same file. Assign an owner and output folder before
starting parallel tasks. Report done, tests and results, risks, omissions, and
hours versus estimate.
